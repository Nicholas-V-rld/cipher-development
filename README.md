# Cipher Development Website

> Built by Daniel Oyinloluwa and Nicholas V. as a team.

Production-oriented Next.js App Router website for Cipher Development.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run lint
npm run build
npm audit --omit=dev
```

## Routes

- `/` — Homepage
- `/product-engineering` — Product engineering, WordPress, rescue and modernization
- `/ai-automation` — AI agents, n8n/MCP automation and managed operations
- `/work` — Selected work index
- `/how-we-work` — Delivery system
- `/about` — Team and company positioning
- `/contact` — Qualified project intake
